# Colleague - Tomato-Themed Romantic Apology React Web Application 🍅❤️

An interactive, animated tomato-themed apology website built with React, Vite, Framer Motion, Tailwind CSS, Canvas particle animations, and EmailJS.

## Features
- 🍅 **Tomato Floating Animation**: HTML5 Canvas floating particle effects & cute tomato mascot.
- ❤️ **Apology & Acceptance**: Dual initial apology acceptance buttons.
- 📜 **10 Reasons Deck**: Interactive step-by-step reason card deck with progress tracking.
- 📧 **EmailJS Integration**: Real-time email notifications for website opening, initial acceptance, reason viewing, and final acceptance.
- 🥺 **"Pls Ek Chance De" Final Proposal**: Dual final acceptance options with celebratory confetti.
